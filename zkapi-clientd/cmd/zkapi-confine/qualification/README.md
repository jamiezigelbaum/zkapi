# Linux x64 host qualification

This is the fail-closed matrix and its helpers from the reviewed Olympus
prototype at `afdb5406`. Normal rows execute the **built production binary**.
A separate `qualification` build supplies ablations and lifecycle helpers;
`qualification,qualification_adversary` supplies the compromised-init fixture.
Neither fixture belongs in a release bundle. Fault injection, ABI emulation
and the socket-pair knob no longer exist as runtime switches. Forced hardening,
descriptor failures and go-handshake refusal are now Go unit tests. The old
silent-launcher fault row is replaced by the unit-tested waiting go handshake;
it does not constitute an integrated supervisor-timeout test.

Run on an ordinary-user Omarchy-class **Linux x86_64** host with usable user,
network and PID namespaces, Landlock ABI >= 4, seccomp, `/proc`, pinned Go
`go1.27.1` (from `olympus/build.sh`), and Bun or Node. No sudo and no kernel
policy changes. A restricted build container can run unit tests and verify
refusal, but cannot qualify namespace isolation. The real host run is an owner
acceptance step; successful CI is not this evidence.

From a committed checkout at the fork root:

```sh
bash zkapi-clientd/olympus/build.sh linux-amd64
fixtures="$PWD/zkapi-clientd/build/confine-qualification"
bash zkapi-clientd/cmd/zkapi-confine/qualification/build.sh "$fixtures"
launcher="$PWD/zkapi-clientd/olympus/dist/bin/zkapi-confine"
"$launcher" --version
"$launcher" check
bun zkapi-clientd/cmd/zkapi-confine/qualification/matrix.mjs \
  --launcher "$launcher" \
  --ablation-launcher "$fixtures/zkapi-confine-ablation" \
  --init-launcher "$fixtures/zkapi-confine-init" \
  --gostandin "$fixtures/gostandin" --mode full \
  --out "$fixtures/omarchy-full.json"
```

Repeat with `node` instead of `bun` (`--mode quick` omits the broad ablation
section; full mode is required for acceptance). Preserve stdout alongside the
JSON report and record kernel, runtime versions, commit, production/fixture
hashes and build environment. `RESULT: PASS (0 failures)` and exit 0 are both
required. A missing row or refused host is a failure, never a skip. The full
matrix deliberately weakens confinement only in test fixtures and cleans up
its own processes; run it in a checkout without credentials in the environment.

The matrix covers inherited descriptors, raw syscalls, descendants, bridge
integrity, socket replacement, status forgery, listener inspection, lifecycle
kills, refusals, HTTP framing and ablation negative controls. The HTTP adapter
here is a qualification helper, not Olympus transport integration. Optional
`--old-fetch PATH` retains comparison with the earlier broken HTTP parser;
that historical file is not shipped. `refusal_probe.py` is the standalone
namespace-policy diagnostic from the prototype.

## Preserved scope and limits

The launcher is network confinement, not a filesystem sandbox. It does not
activate the Olympus Linux private lane. arm64 is refused, not qualified.
The 64-slot bridge limit bounds pending authentication/descriptor handoff as
in the prototype, **not all established pumps**. Pumps retain the prototype's
30-second drain grace after one direction finishes and two-second dial and
handshake deadlines. Tests pin these behaviors without changing them.

The golden seccomp fixture was generated by the reviewed prototype's
`dumpfilter` on Linux amd64 with all prototype environment switches unset,
using the pinned Go toolchain. It must not be regenerated to bless a policy
change without a separate review of that change.
